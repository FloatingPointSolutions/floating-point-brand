identity.

floating point is an engineering solutions company. the identity is the period: the point at the end of the word.

01 · lowercase

wordmark, headlines, captions, ui copy. proper nouns excepted.

02 · neutrals only

five colors. no chroma above 0.02.

03 · the dot is the system

status indicator, loading cursor, favicon, app icon, brand. one shape across surfaces.

04 · motion is reserved

the bounce plays at boot. never decorative. never inside ui.

3

usage

  • first paint plays on mount. not on hover, scroll, repeat interaction.
  • wordmark only reserved for the period. not on icons, ui, copy.
  • scales hero (≥ 240px), tile (≤ 120px). do not author new sizes.
  • accessibility honors prefers-reduced-motion: static wordmark, no animation.
